## Bukti independen dan batas keputusan

- **OCI dan Compose.** Artefak push `18eb64d` dan `c67c955` diperiksa terhadap SHA-256, label commit, user, CA dan subject provenance. Uji regresi membangun dengan dua nilai SOURCE_DATE_EPOCH, lalu kembali ke nilai pertama dan membandingkan digest manifest. Pemeriksaan timestamp menolak layer versi lama. Artefak push `deff77b` dan rebuild lokal menghasilkan manifest identik `sha256:8cf646ac99fa2fd3c6566fa9aba554576a4abe208a87e223ca046d724e75a0c8` serta digest konfigurasi identik. Artefak event PR diperiksa pada commit integrasi sintetis `1997dcb`. Index memuat metadata attestation yang dapat berubah. Signing dan trust registry target masih memerlukan keputusan Ops. Konfigurasi Compose memuat satu API di loopback, UID/GID 65532, root filesystem read-only, cap-drop ALL, no-new-privileges, restart, batas CPU/RAM/PID, healthcheck dan rotasi log. [Artefak push](https://github.com/PTKPP/hi-ve/actions/runs/45342996817/artifacts/14896208851) · [Artefak pull request](https://github.com/PTKPP/hi-ve/actions/runs/45343005860/artifacts/14896652695)
- **Runtime dan PostgreSQL.** Tes probe, pool jenuh, kegagalan koneksi, hostname/CA salah, shutdown HTTP dan WebSocket 1001 serta replay cursor dijalankan. Grace period Compose 25 detik meliputi batas drain HTTP/socket 15 detik. Worker cleanup dan Push menerima context pembatalan dan ditunggu sebelum pool ditutup. Delivery Push tetap at-most-once dengan fallback feed.
- **Batas regresi.** Tujuh suite memakai login `hive_app` untuk panggilan service online. Cakupannya provisioning/OIDC dan cleanup auth, pairing, histori login, PIN dan checkout operator, Sales/Inventory, Reports/Realtime, serta lifecycle/transfer Owner. Seed, simulasi error, dan observasi dilakukan dengan koneksi fixture. Suite lain memakai role fixture atau role yang ditentukan suite masing-masing. Fixture Offline tersendiri memakai database disposable. Binary standar tetap menolak rute Offline. Batas migrasi development tetap 028.
- **Migrasi.** Fresh 001–055, upgrade 054→055, lock timeout, concurrent retry, rollback DDL, penolakan approval pairing lama dan M5 lintas binary diuji. Rollback image mensyaratkan digest yang sudah dibuktikan memeriksa epoch 055. Tanpa digest itu, tahan trafik dan lakukan roll-forward.
- **Ingress dan browser.** Template Tunnel lulus validasi lokal. Callback cocok ke API loopback dan `/readyz` ke 404. Tiga frontend dibangun static-only, dua tes Node dan 28 Chromium lulus. Source membatasi origin, cookie host-only Secure/HttpOnly, OIDC state/nonce, cache API no-store dan SMTP TLS. Peer lokal Tunnel dapat berbagi kuota antarperangkat.

**STAGING DEPLOYMENT READY · NOT VERIFIED.** Ops perlu membuktikan firewall/TLS dan ACL efektif pada kedua VM, digest registry, HTTPS/WSS, cache, OIDC dan SMTP nyata, serta penyimpanan WAL terenkripsi off-VM dengan alarm dan restore terukur. RPO/RTO dan retensi memerlukan keputusan pemilik. **PILOT READY · NOT VERIFIED.** UAT fisik Android/iOS, PBKDF2, printer, Web Push dan kapasitas/p95 pilot masih menjadi gate Phase 08.
